# Security Policy

AxonLink is designed for authorized remote workflow replication only.

Please do not report requests for covert access, credential extraction, stealth persistence, unauthorized remote control, or access-control bypass as feature requests. They are outside the scope of this project.

## Supported versions

The project is currently in early development. Security-sensitive behavior may change between versions.

## Reporting a vulnerability

Open a private security advisory on GitHub if available, or contact the repository owner through the preferred GitHub security channel.

When reporting, include:

- affected version or commit;
- exact skill instruction or script involved;
- expected behavior;
- observed unsafe behavior;
- minimal reproduction steps that do not include secrets.

Do not include live credentials, tokens, private keys, cookies, raw `.env` values, or sensitive hostnames in reports.
