# Contributing

Contributions are welcome when they strengthen safe, authorized workflow replication.

Preferred contribution areas:

- clearer Claude Code skill instructions;
- safer command classification;
- better target verification;
- Windows and PowerShell support;
- workflow recipe examples;
- test fixtures;
- documentation improvements.

Out of scope:

- stealth features;
- credential extraction;
- unauthorized access;
- persistence mechanisms;
- bypassing access controls;
- disabling logs or security tools;
- broad network scanning.
